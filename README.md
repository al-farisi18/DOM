# DOM
1. querySelector() dan querySelectorAll()
Pengertian

querySelector() digunakan untuk memilih satu elemen HTML berdasarkan selector CSS.

Sedangkan querySelectorAll() digunakan untuk memilih semua elemen yang cocok dengan selector CSS.

2. innerHTML, textContent, dan innerText

Ketiganya digunakan untuk mengakses atau mengubah isi sebuah elemen HTML, tetapi memiliki perbedaan.

A. innerHTML

innerHTML digunakan untuk membaca atau mengubah isi HTML, termasuk tag HTML di dalamnya.

B. textContent

textContent digunakan untuk mengambil atau mengubah teks, tanpa memproses tag HTML sebagai elemen.

C. innerText

innerText digunakan untuk membaca atau mengubah teks yang terlihat oleh pengguna.

3. Manipulasi Atribut dan Style
